### フェーズ5: ストーリーのバトル

終わったときの状態: 草むらで野生と戦える。ライバル戦・道路のトレーナー戦ができる。レベルが上がり、技を覚え、進化する。

- 草むらを1歩進むごとに出会いの判定（マップの出現表から No とレベルを引く）
- バトルの形式「手持ち全員 vs 相手全員（シングル）」を足す（見せ合い・選出なし。先頭から出す。HP を持ち越す）
- コマンドを「戦う / バッグ / ペンモン / 逃げる」にする（ストーリーのときだけ。バッグはフェーズ6まで押せない）
- 逃げる: 野生だけ。素早さで成功率（案: 本家の式の簡略版）
- トレーナー: 目が合ったら「！」→ 近づいてきて会話 → バトル。勝ったら賞金・倒したフラグ
- バトルの後: 経験値の文 → レベルアップ（上がった能力の窓）→ 技を覚える（忘れる技を選ぶ）→ 進化の演出
- 全滅: 「目の前が 真っ暗に なった！」→ 最後に回復した場所（最初は自分の家）へ。お金半分（案）
- 仮の回復: 自分の家の母に話しかけると全回復（ぬくもり小屋はフェーズ6）
- ストーリーの BGM はバトル曲を流用（案）
- 決めたこと（フェーズ5）:
  - 小分け: 5a 純C#（出会い・バトルの準備・逃げる・トレーナー・経験値・お金・回復）/ 5b 野生とのバトル・全滅・母で回復 / 5c トレーナー・ライバル / 5d 経験値・レベルアップ・技を覚える・進化の画面
  - 経験値は **出た子だけ**（倒した相手と場で向き合い、バトルの終わりに瀕死でない子で山分け）。バトルの後にまとめて出す
  - 全滅したら **お金は半分**・手持ちは全回復して、最後に回復した場所へ。最初のお金は 3000
  - 逃げる: 自分の素早さ ≧ 相手なら必ず。遅ければ 自分×128÷相手 ＋ 30×試した回数 を 256 と比べる（本家の第3世代の簡略版）。失敗したら相手だけが動く
  - 賞金はトレーナーごとの固定額。草むらの出会いは1歩ごとに 10%
  - トレーナーは向いている先を見張り（区切り1は3〜4マス）、目が合ったら隣まで歩いてきて台本（会話 → バトル）を流す。勝つと二度と戦わない
  - 8b まで試しの1番道路（12x18。草むら・トレーナー1人）を村の北の出口の先に置く。野生は既存のヒナを進化前にした仮の子（ハネヒナペン・ギョウレツヒナペン Lv2〜4）
  - ライバルは研究所で待ち、最初の1体をもらうと出口の前から目が合って勝負（こちらに強い子・Lv5）。本家と同じく負けても話は進み、博士が回復してくれる
  - 仮の最初の3体には、同じタイプの既存のふつうの子（ナミペン・ヒノペン・ノリペン）を Lv16 の仮の進化先として付ける（`Town01Species`）。Lv8 と進化で技を1つずつ覚える

- 捕獲の式（案: 本家の第3〜4世代の簡略版 ＝ 最大HP・今の HP・種の捕まえやすさ・状態異常から確率を出し、揺れる回数（0〜3）を引く）。タマゴが揺れる演出は今の `EggThrowView` を使い回す
- 手持ちが6体のときは あずかり箱へ送る

- よろず屋: 道具を買う / 売る

- テスト: 捕獲の確率が HP・状態異常で変わる / 手持ちがいっぱいなら箱へ / お金が足りないと買えない
- 決めたこと（フェーズ6）:
  - 小分け: 6a 純C#（バッグ・道具・捕獲の式・あずかり箱・売り買い・博士のタマゴ）/ 6b バトル中のバッグ・捕獲の演出 / 6c ぬくもり小屋・よろず屋 / 6d フィールドのメニュー
  - 道具は5種: 捕獲タマゴ 200円・傷薬（HP20）300円・毒消し（毒・猛毒）100円・麻痺治し 200円・目覚まし 250円。売ると半額。火傷・氷を治す道具は区切り1では無し
  - 最初の1体と一緒に、博士が捕獲タマゴを 5個 くれる
  - 捕獲: 値 ＝ (3×最大HP − 2×今のHP) × 捕まえやすさ ÷ (3×最大HP) × 状態異常（眠り・氷 2倍、ほか 1.5倍）。255 以上なら必ず。それより下は揺れの判定を4回引き、全部通れば捕まえる（揺れは3回見せる）。捕まえやすさは本家に合わせる（仮の最初の3体 45・仮の野生 255）。捕まえても経験値は無し

  - 8b まで、ぬくもり小屋・よろず屋は村に仮の建物を2つ置く（中は 8x6・受付の人が1人）
