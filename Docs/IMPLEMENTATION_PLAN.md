# ペンモン 実装計画書

> 各フェーズは「週末1〜2回で終わる大きさ」「終わったら Playable Build が残る」を目安に切る。中身は `Docs/Plan/PHASE_XX.md` に1フェーズ1ファイルで書く。先のフェーズは着手するときに詰める。

## 進め方

- 1フェーズ = 1つ以上の feature ブランチ → PR → main へ Merge
- フェーズの完了条件を満たしたら Playable Build を残す
- 仕様が変わったら `Docs/PENGUIN_MONSTER_SPEC.md` も更新する
- 先のフェーズの機能を前倒しで作り込まない（ただしダブルス用に「場の数」を持たせておくなど、後で作り直しになる設計だけは先に入れる）
