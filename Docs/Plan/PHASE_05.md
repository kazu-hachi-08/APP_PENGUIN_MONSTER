**完了条件:** 勝ち抜き戦を最初から最後まで遊べ、最高記録が残る。

## 作ったもの

- 勝ち抜き戦は純C#の `SurvivalRun`（`Battle/Survival/`）。連勝数・何戦目か・ボス戦か・次の相手（`SurvivalOpponent`: 6体と CPU、ボスなら `BossDefinition`）を持つ
- 画面の流れは `GameFlow`: タイトル → ドラフト → [試合前の画面 → 見せ合い・選出 → バトル → 結果] を負けるまでくり返す。結果の文面は `GameFlow.Result.cs`
- 試合前の画面 `BattleIntroPanel`: 「Nせんめ」と今の連勝数。ボスは背景が赤くなり、名前・セリフ・先頭のペンモンが「ぽよん」と出る。どこを押しても次へ
- 結果は共通基盤の `ResultDialog`。勝ち:「つぎの たたかいへ」/「タイトルへ」、負け: 連勝数と最高記録（しんきろく！）→「タイトルへ」。`ResultDialog` は onRetry が無いときに「もう一度」ボタンを隠すようにした
- CPU の賢さ `CpuLevel`（よわい / ふつう / つよい）。ふつうは `DamageCalculator.Expected`（乱数なし・命中率込みの見込みダメージ）が一番大きい技、つよいはタイプで不利なら相性のいい控えに交代し、ひんしの後も相性で選ぶ
- 切り替え: 1〜3戦目 よわい / 4〜6戦目 ふつう / 7戦目から つよい（ボスはいつも つよい）。CPU のドラフトは連勝数 × 10% で種族値の合計が一番高いのを取る
- ボス `BossTable`: 7戦目 ユキオ（こおり）/ 14戦目 ライカ（かみなり・とり）/ 21戦目 ヨミ（やみ・オーロラ）。その先はくり返し
- セーブ: 共通基盤に `BestScore`（PlayerPrefs、キーで分ける）を足して最高連勝数を保存。勝つたびに更新。タイトルに表示。途中経過は保存しない
- `BattleController` は試合の始めに場を空にする（同じ場で続けて戦うため）
- テスト `CpuPlayerTests`（技選び・交代・ひんし後の選び方・ドラフトの取り方・見込みダメージ）/ `SurvivalTests`（賢さの切り替え・ボスの順番とチーム・相手の作り方）

## 決めたこと（仕様書に「案」で書いた。遊んでみて見直す）

- 賢さの切り替えの戦数、ボス3人の中身、強く取る確率の上がり方
- 途中経過は保存しない
