## 作ったもの

- 種類は enum（`Ability` / `HeldItem`、`Battle/Data/`）＋名前・説明の表。効果ごとのクラスは作らず、発動する場所に switch / if で書いた（各10種ならこの方が追いやすい）
- 発動の場所
  - 場に出たとき（こわもて）・攻撃のあと（いきおいづく・物理を受けた側の特性・いのちのつらら）・ターン終わり（おいかぜのり）: `BattleEngine.Abilities.cs`
  - HP が減ったとき（おやつのイカ）・状態異常になったとき（さっぱりこんぶ）・たおれる攻撃（ふんばりマフラー）・ターン終わり（ほしざかな）: `BattleEngine.Items.cs`
  - ダメージの倍率（せとぎわ・ふかふかしぼう・かたいはね・はね・つらら・メガネ・コート）: `DamageCalculator.Modifier`。CPU の見込みダメージにも同じ倍率が入る
  - すばやさ（かるいはね）: `BattleMonster.EffectiveSpeed` / ねむらない（よふかし）: `StatusImmunity`
- 「1回だけ」の持ち物は `BattleMonster.ItemUsed` で持つ
- `BattleEvent` に6種類（`AbilityActivated` / `AbilityDamage` / `ItemHealed` / `ItemCured` / `ItemEndured` / `ItemRecoil`）を末尾に足した。HP はイベントに載るので、オンラインの送る形（8 int）は変えずに同期できる
- ドラフトのカードを縦に少し伸ばし（720 → 780）、絵を小さくして、タイプの下に「とくせい / もちもの」と説明を出す
- テスト `AbilityItemTests`（各特性・持ち物の効果、定義表で全種類が使われていること）。`OnlineCodecTests` の写しの確認を24体全員ぶんに広げた
