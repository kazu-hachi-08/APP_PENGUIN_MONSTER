# Phase 2: ダイパ風のバトル画面

**目的:** Phase 1 の仮画面を、ダイヤモンド・パール風の見た目にする。

**仕様書:** §6 画面・ビジュアル / §7 UI・演出・サウンド

- [x] ペンモンのドット絵をコードで生成（基本ペンギン＋パーツ。正面・後ろの2枚、64x64 案）。前作の合成の仕組みを参考にする
- [x] パーツの種類を決めて仕様書に書く
- [x] 背景（地面の楕円の台座・空）
- [x] 名前・HPバーの枠（HP の色が緑→黄→赤）、HP が減るアニメーション
- [x] メッセージ窓（一文ずつ送る。タップで次へ）
- [x] コマンド（たたかう / ペンモン / ※にげるは無し）と技選択（タイプ色付き）
- [x] 簡単な演出（攻撃時に揺れる、ダメージで点滅、ひんしで下に消える、出てくる）
- [x] 仮の SE（コード生成でよい）

**完了条件:** Phase 1 と同じ遊びが、ダイパ風の画面で最後までできる。

## 作ったもの

- 見た目の定義 `MonsterLook`（体型・体の色・頭・首）を `MonsterDefinition` に追加し、仮の6体に割り当てた
- ドット絵は PNG にせず実行時に生成（`View/Art/`）。楕円・三角を重ねて塗り、最後に1ドットの輪郭を付ける
- 背景・台座も実行時に生成（`BattleBackdrop`）。シーン上では白い四角のまま
- SE は `BattleSounds` がクリップを作り、共通基盤の `AudioManager.PlaySeClip` で鳴らす（共通基盤の `SeId` には足していない）
- テスト: 見た目の省略時の既定値、定義表の見た目が重複しないこと
