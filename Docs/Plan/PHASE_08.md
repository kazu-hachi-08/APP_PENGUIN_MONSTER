# Phase 8: ずかん・タイプ相性表・あそびかた・設定

**目的:** タイトルのメニューをそろえる。

**仕様書:** §2.0 / §9

- [x] ずかん（絵・タイプ・種族値・技・特性・持ち物）、タイプでしぼりこみ
- [x] タイプ相性表（§3.4 をそのまま表示）
- [x] あそびかた（ドラフト・選出・バトル・勝ち抜き戦の説明）
- [x] 設定（BGM・SE の音量、メッセージの速さ）とセーブ

**完了条件:** タイトルのメニューがすべて押せる。

## 作ったもの

- 4画面とも `SubMenuPanel`（左上の「もどる」でタイトルへ）を土台にした。開く・戻るは `TitlePanel` の中で完結させ、`GameFlow` は変えていない
- ずかん `DexPanel`: しぼりこみは純C#の `MonsterTable.WithType`、技の説明（分類・威力・命中・先制・効果）は `MoveDescriptions`。技表から文を作るので、技を足しても説明を書かなくてよい
  - 一覧のマスは定義表の体数ぶんシーンに作り、しぼりこんだ数だけ使う
- タイプ相性表: `TypeChart` の値を SceneBuilder が生成時にマスへ焼き込む（実行時に変わらないので専用のコンポーネントは無し）。相性を変えたら Rebuild
- あそびかた `HowToPanel`: タブ4つ。文面はクラスの中の定数
- 設定 `SettingsPanel`: 音量は共通基盤の `AudioManager`（閉じるときに保存）、メッセージの速さは `GameSettings`（PlayerPrefs、押したら保存）。`MessageWindow` が1文ごとに倍率を読む
- ドラフトとずかんで共通の部分を外へ出した: タイプの札の塗り（`TypeColors.PaintBadges`）、種族値・特性の文面（`MonsterTexts`）
- タイトル画面をゲームらしくした（仕様書 §2.0）: 遊ぶボタン2つを大きく、ほかは下の列に。雪 `TitleSnow`（別 Canvas にして毎フレームの作り直しをメニューに広げない）と、雪原を歩くペンモン `TitleWalker`。ボタンは角丸の `ChunkyButton`（絵は `ButtonArt`、9スライス）、ロゴは1文字ずつ動く `TitleLogo`
- テスト `DexTests`（しぼりこみ・技の説明）
- シーンは batchmode で Rebuild 済み。EditMode テスト 145 件すべて通過
