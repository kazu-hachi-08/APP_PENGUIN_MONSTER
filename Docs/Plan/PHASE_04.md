# Phase 4: タイトル〜ドラフト〜選出〜結果

**目的:** CPU 戦1試合を、タイトルから結果まで通しで遊べるようにする。

**仕様書:** §2 ゲームの流れ / §2.1 ドラフト / §2.2 見せ合い・選出

- [x] タイトル画面（勝ち抜き戦 / オンライン対戦 / ずかん / タイプ相性表 / あそびかた / 設定。未実装は押せない）
- [x] ドラフト（純C#: 3体提示×6回、取ったペンモンは出ない）。カードに絵・名前・タイプ・種族値
- [x] CPU のドラフト（ランダム）
- [x] 見せ合い・選出（3体と先頭を選ぶ）
- [x] 結果画面（勝ち / 負け → タイトルへ）
- [x] テスト（ドラフトの抽選・重複なし）

**完了条件:** タイトル → ドラフト → 選出 → バトル → 結果 → タイトルがつながる。

## 作ったもの

- 画面の流れは `GameFlow`（タイトル → ドラフト → 見せ合い・選出 → バトル → 結果）。`BattleController` はチームを受け取ってバトルだけを回す
- ドラフトは純C#の `Draft`（`Battle/Draft/`）。自分がまだ取っていない中から純ランダムに3体。提示数・回数は `BattleBalance.DraftOfferCount / DraftRounds`
- CPU のドラフト・選出は `CpuPlayer.RunDraft / ChooseTeam`（どちらもランダム）。CPU の提示はプレイヤーとは別に引く
- タイトル `TitlePanel`: 「勝ち抜き戦」だけ押せる（いまは CPU と1試合。連戦は Phase 5）。他のメニューは並べて押せなくしてある。左右に飾りのペンモン
- ドラフト `DraftPanel`: 3枚のカード（絵・名前・タイプの札・種族値と合計）。押したら即決定。下の帯に取ったペンモン
- 見せ合い・選出 `SelectPanel`（Phase 3 の仮の `PickPanel` を作り替え）: 上に相手の6体、下の自分の6体から押した順に3体（1番目が先頭）。「おまかせ」で残りをランダム
- 結果は共通基盤の `ResultDialog`（「もう一度遊ぶ」は外して「タイトルへ」だけ）。タイトルへはシーンの読み直し
- テスト `DraftTests`: 提示は3体で重複なし・取ったペンモンは出ない・6回で終わり・全ペンモンが出うる・CPU のドラフトと選出
