# Phase 3: 状態異常・能力変化・技表・24体

**目的:** バトルの仕組みを原作並みにし、最初の 24 体をそろえる。

**仕様書:** §3.5 / §4.2 / §4.4 / §4.5

- [x] 状態異常（まひ・どく・もうどく・やけど・ねむり・こおり・こんらん）
- [x] 能力変化（ランク -6〜+6、交代で戻る）
- [x] 変化技・追加効果（〇%でまひ、こうげき↑ など）
- [x] 先制技（優先度）
- [x] 技表を 24 体に足りる数にする（目安 40〜50 個）
- [x] ペンモン 24 体の定義表（各タイプ2〜3体、こおり多め）と見た目のパーツ指定
- [x] 状態異常のアイコン・メッセージ・演出
- [x] 相性表を 24 体で見直す
- [x] テスト追加（状態異常のダメージ・行動不能、ランク倍率）

**完了条件:** 24 体から好きな3体ずつ（仮の選択画面）で CPU と戦える。

## 作ったもの

- 状態異常は `StatusCondition`（1体に1つ・交代で残る）、こんらんは `BattleMonster` の別枠（交代で治る）。判定とターン終わりは `BattleEngine.Status.cs`
- 能力変化は `StatKind` と `StageMultiplier`。命中は（命中ランク − 回避ランク）の1つの倍率。急所は下がった攻撃・上がった防御を無視
- 技の効果は `MoveEffect`（状態異常 / こんらん / ランク）。攻撃技は追加効果、変化技（`MoveCategory.Status`）は効果そのもの。`BattleEngine.Effects.cs`
- 技表 48 個（各タイプ3〜7個、先制技3つ）、ペンモン 24 体（こおり5体、他は2タイプも数えて各2〜4体）。技名・ペンモン名はオリジナル
- 見た目の頭パーツに「せびれ」（やみ用）を足した。24 体の組み合わせは全部ちがう
- 相性表は「やみ → ひ」「オーロラ → ひ」を等倍に（仕様書 §3.4）
- 名前の枠に状態異常の印、状態異常・能力変化で光る演出と SE、技ボタンの変化技は「へんか」表示
- 仮の選択画面 `PickPanel`: 24 体から自分の3体 → 相手の3体を選ぶ（選んだ順が出る順、「おまかせ」でランダム）
- テスト: 状態異常のダメージ・行動不能・タイプで効かない・交代で残る / 戻る、ランク倍率・上限・交代・急所、定義表の形（24体・技4つ・40〜50個）
- 参考: CPU（よわい）同士で 2000 戦させると、勝率は 36%（ツバサペン）〜 67%（オーロペン）。調整は Phase 9
