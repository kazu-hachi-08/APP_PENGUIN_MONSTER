## 作ったもの

- タイトルの「オンライン対戦」→ 共通基盤の `ModeSelectPanel`（部屋を作る / コードで参加。CPU 戦ボタンは隠した）。流れは `GameFlow.Online.cs`: ドラフト → 6体を送り合う → 見せ合い・選出 → 3体を送り合う → バトル → 結果 → タイトル
- 通信路 `OnlineLink`（`Scripts/Online/`）: 名前付きメッセージ1つに「種類・int 列」を載せて送り、届いたものは種類ごとに貯める。接続のコールバックの中ですぐ開く（ホストは接続直後に種を送るため）
- ドラフト: ホストが種を決めて送り、ゲストはその種で `Draft` を引く。候補を1回ずつ送り合うより通信が少なく、提示はお互い別々なので結果は同じ
- バトル: `BattleController.Online.cs`。ホストは `BattleEngine` で計算して `BattleEvent` を送ってから再生。ゲストは陣営を入れ替えた写しの `BattleState` を持ち、届いたイベントで写しを更新して再生（交代の画面・ひんしの入れ替えはオフラインと同じ `BattleSide` で動く）
- 送る形への変換は純C# の `BattleEventCodec` / `OnlineCodec`（`Battle/Online/`）。ペンモンは「陣営・選出の何番目か」、技は「何番目か」、チームは No の列
- 制限時間 `CountdownTimer`（ドラフト15秒・選出60秒・1ターン30秒。ひんしの入れ替えも30秒）。秒数は `BattleBalance.Online*Seconds`。CPU 戦では隠れたまま
- 切断: `OnlineSession.OnPeerDisconnected` で流れを止め、「かち！ あいてが せつだんしました」→ タイトル。決着の後は購読を外して無視する
- テスト `OnlineCodecTests`（行動・6体の往復、陣営の入れ替え、ホストのバトルを最後まで進めて写しが同じ状態になるか）

## 決めたこと（仕様書に書いた）

- 選出の時間切れは、選びかけのぶんを残して足りないぶんを上から埋める
- ひんしの入れ替えの時間切れは、出せる中で一番上
- オンラインは1試合ごとに部屋を作り直す（再戦ボタンなし）。勝敗は記録しない
