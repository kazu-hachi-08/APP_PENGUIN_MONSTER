# ペンモン 仕様書

> 対話で中身を決めながら埋めていく。未定の項目は「未定」と書いておく。「（案）」は Claude の提案で、まだ確認していないもの。

## 1. 概要

ペンギンだけのモンスターをドラフトで集めて戦う、ターン制の対戦ゲーム。見た目と手触りはダイヤモンド・パール風の2D。ストーリーやフィールド探索はない。

| 項目 | 内容 |
| --- | --- |
| アプリ名 | ペンモン |
| ジャンル | ターン制モンスター対戦（3vs3 シングル / 4vs4 で2体ずつ場に出るダブルス） |
| グラフィック | 2Dドット絵（ペンギンは1体ずつのデザインをコードで生成） |
| プレイ人数 | 1人（勝ち抜き戦・CPU戦）/ 2人（オンライン・参加コード） |
| 1試合の長さ | 5〜10分が目安 |
| ペンモンの数 | 最初 24 体 → 50 → 75 → 150 体と段階的に増やす（いまは 150 体） |
| プラットフォーム | Android / Windows / ブラウザ（WebGL）。横画面固定 |

### 1.1 モード

| モード | 編成 | 相手 | ゴール |
| --- | --- | --- | --- |
| 勝ち抜き戦（1人） | 最初にドラフトで6体。最後まで同じチーム | CPU（勝つほど強くなる） | 何連勝できるか。7戦ごとにボス |
| オンライン対戦（2人） | 毎回ドラフトで6体 | 友達（参加コードで接続） | 相手の3体（ダブルスは4体）を全員たおす |

- どちらのモードも、最初にシングルかダブルスかを選ぶ（§4.9）。オンラインは部屋を作った側（ホスト）が選ぶ

### 1.2 権利まわりの方針

ゲームの仕組み（タイプ相性・種族値・ダメージ式など）はポケモンを参考にするが、タイプ名・技名・特性名・持ち物名・見た目はすべてオリジナルにする。

## 2. ゲームの流れ

```text
タイトル
 ├ ストーリー（作成中）→ 自分の家で始まり、仮のハツユキ村を歩く・人と話す・研究所で最初の1体をもらう → ライバル戦 → 試しの1番道路で野生・トレーナーと戦う（B でタイトルへ戻る）
 ├ 勝ち抜き戦 → シングル / ダブルス → ドラフト → 持ち物 → [見せ合い → 選出 → バトル → 結果] をくり返す（負けたら終わり）
 ├ オンライン対戦 → 部屋を作る / コードで参加 → シングル / ダブルス（ホストが選ぶ）→ ドラフト → 見せ合い → 選出 → バトル → 結果
 ├ 図鑑
 ├ タイプ相性表
 ├ 遊び方
 └ 設定
```

### 2.0 タイトルから開く画面

タイトル画面の見た目:

- 夜空（紺）に雪が降り、下は雪原。雪原の上を、ランダムなペンモンが左右どちらかから ぴょこぴょこ跳ねて横切る（2体。画面の外に出たら少し待って別のペンモンで入り直す）
- 上にロゴ「ペンモン」とサブタイトル。ロゴの左右に飾りのペンモン
  - ロゴは1文字ずつ色（黄・水色・オレンジ・白）と傾きを変え、白と紺の2重の縁取り＋影。開くたびに1文字ずつ「ぽよん」と出て、そのあと波打つように上下に揺れる
- タイトルのボタンは角丸で厚みのある「ぷっくり」ボタン（コードで作るドット絵）。押している間は面と文字が沈む
- まん中に大きなボタン「ストーリー」「勝ち抜き戦」「オンライン対戦」、その下に最高連勝数のバッジ（シングル・ダブルスの2つを1行に）
- 下に小さなボタンを横一列: 図鑑 / タイプ相性表 / 遊び方 / 設定

どれも左上の「戻る」でタイトルへ戻る。

ストーリー（作成中。計画は `PLAN_STORY_TOWN01.md`）:

- フィールドは1マスずつ歩く 2D マップ。画面の縦に約9マスが入り、カメラは主人公を追う（マップの端では止まる。マップが画面より小さい家の中などは中央に置き、まわりは黒）
- 操作: PC は矢印・WASD で歩き、Z が A・X が B。タッチの端末だけ、画面の左下に十字キー・右下に A / B を出す
- 押しっぱなしで歩き続ける。壁・木・水・看板・人に向かって押すと向きだけ変わる。扉に乗ると暗転して建物の中（外）へ移る
- 今は B でタイトルへ戻る（フェーズ6でメニューにする）。進み具合はまだ保存しないので、始めるたびに自分の家から（セーブはフェーズ7）
- 人・看板の前で A を押すと会話窓。会話窓はバトルのメッセージ窓と同じ見た目・送り方（§7）で、A / B・窓や画面のタップで送る。話しかけた人はこちらを向く。会話の間は十字キーを隠す
- 「はい / いいえ」は会話窓の右上に重ねる。押して選ぶほか、PC は上下で ▶ を動かして A で決める。B は いいえ
- 人の立つ場所とセリフは物語のフラグで変わる（例: 最初の1体をもらうまで、村の北の出口を母がふさぐ。もらった後は家に戻る）
- 研究所の博士に話しかけ「はい」と答えると、最初の3体を選ぶ画面。ドラフトと同じ形で、左に「海 / 火 / 苔の タマゴ」のカード3枚、押すと右に中身の詳細、「この子に 決めた！」→「〇〇に しますか？」はい で Lv5 の子が手持ちに入る（いいえで選び直し）。PC は上下で選んで A で決める
  - 本物の最初の3体（No.151〜159）はまだ無いので、今は既存のヒナ（ウキワヒナペン・マッチヒナペン・フタバヒナペン）を進化前（綿毛なし）にして仮に渡す
- 村の人の絵は主人公と同じ形の色違い。看板は通れないマスで、前から A で読む
- バトル（フェーズ5）: 手持ち全員 vs 相手全員のシングル。見せ合い・選出はなく、手持ちの先頭の元気な子から出る。HP・状態異常は戦いの後も残る。曲は対戦のバトル曲
  - コマンドは「戦う / バッグ / ペンモン / 逃げる」（2x2）。バッグはフェーズ6まで押せない。逃げるは野生だけ（自分の素早さ ≧ 相手なら必ず。遅ければ 自分×128÷相手 ＋ 30×試した回数 を 256 と比べる。失敗したら相手だけが動く）
  - 野生: 草むらを1歩進むごとに出現表の確率（試しの1番道路は 10%）で出会う。タマゴから出ず「あっ！ 野生の 〇〇が 飛び出してきた！」。文の主語は「野生の 〇〇」。戦える子がいないときは出会わない
  - トレーナー: 向いている先（区切り1は3〜4マス）に入ると、頭の上に「！」→ 隣まで歩いてくる → 会話 → 「〇〇が 勝負を しかけてきた！」。話しかけても戦える。勝つと「賞金 〇円を 手に入れた！」でお金が増え、二度と戦わない
  - ライバル: 最初の1体をもらうと研究所の出口の前から勝負を挑む（こちらに強い子・Lv5）。負けても話は進み、博士が回復してくれる
  - 戦いの後: 倒した相手と向き合って最後まで立っていた子で経験値を山分けする（本家の第5世代の簡略版。トレーナーの子は 1.5 倍）→「〇〇は レベル N に 上がった！」と能力の窓（上がった分 → 次のタップで新しい値）→ 技を覚える。技が4つ埋まっていたら技の窓で忘れる技を選ぶ（戻る なら覚えない）→ この戦いでレベルが上がり、進化のレベルに届いた子は進化（前と後の絵がだんだん速く入れ替わる）
  - 全滅: 「目の前が 真っ暗に なった！」→ お金が半分になり、手持ちを全回復して、最後に回復した場所（最初は自分の家）へ戻る。最初のお金は 3000
  - 回復: ぬくもり小屋（フェーズ6）ができるまでは、自分の家の母に話しかけると全回復
  - 本物の新しいペンモンはまだ無いので、仮の最初の3体は同じタイプの既存の子（ナミペン・ヒノペン・ノリペン）に Lv16 で仮に進化し、Lv8 と進化で技を1つずつ覚える。野生は既存のヒナを進化前にした仮の子（ハネヒナペン・ギョウレツヒナペン）
- 交代の画面はストーリーの手持ちに合わせて6枠（対戦では選出の数だけ出す）

各画面の見出し（図鑑・ドラフトの「欲しい ペンモンを 選んでください」など）は、白い文字にロゴと同じ紺の縁取り1重＋小さな影（ロゴのような2重の縁取りや黄の文字だと、画数の多い漢字がつぶれて読みにくかったため）。

- 図鑑: 上の帯でタイプをしぼりこむ（すべて + 10タイプ。2タイプのペンモンはどちらでも出る）。左の一覧（13列 x 12行。150体が1画面に収まる）で押したペンモンの 絵・No・名前・タイプ・種族値・特性（説明つき。ヒナは綿毛の補正も）・技4つ（タイプ・分類・威力・命中・先制・効果）を右に出す
- タイプ相性表: §3.4 の表をそのまま出す（2 は赤・½ は青・0 は灰。等倍は空欄）
- 遊び方: タブで ドラフト / 選出 / バトル / ダブルス / 勝ち抜き戦 を切り替える。文面は `HowToPanel` が持つ（ルールを変えたら合わせて直す）
- 設定: BGM・効果音の音量（スライダー）、メッセージの速さ（遅い 0.5倍 / 普通 / 速い 2倍）

### 2.1 ドラフト

- ランダムな3体から1体を選ぶ×6回で6体そろえる
- 提示はプレイヤーごとに別々。相手と同じペンギンを取ってもよい。自分がすでに取ったペンギンは出ない
- 候補は全ペンモンからランダム。ただしランク（§3.5）ごとに出やすさの重みを付ける（ヒナ・ふつう 10 / エース 5 / 伝説 2）。タイプの偏りの補正はしない
- 伝説はチームに1体まで。伝説を取ったら、そのあとの提示に伝説は出ない（伝説だけで固めた壊れたチームを防ぐ）
- 重みと上限はバランス定義クラスに置く（`DraftWeightHina` / `DraftWeightNormal` / `DraftWeightAce` / `DraftWeightLegend` / `MaxLegendsPerTeam`）
- オンラインは1回15秒。過ぎたら3体からランダム
- オンラインの抽選: ホストが種（seed）を決めてゲストへ送り、ゲストの端末はその種で自分の提示を引く（提示はお互い別々で、相手の取り方に左右されないため）
- 提示数（3）・回数（6）・制限時間（15秒）はバランス定義クラスに置く（`DraftOfferCount` / `DraftRounds` / `OnlineDraftSeconds`）
- 画面は「左に提示の小さいカード3枚（絵・名前・タイプ）、右に選んでいる1体の大きな詳細」。カードを押すと詳細が切り替わり、詳細の下の「これに 決めた！」で決定する（選ぶ → 決めるの2段）
  - 配るたびに1枚目を選んだ状態から始める（空の詳細を見せないため）。選んでいるカードは黄色の縁で囲む
  - 詳細: 上の紺の帯に 絵・名前・タイプの札・種族値の合計（右端の金の縁のバッジ）。その下に「特性」の枠（持ち物・ヒナの綿毛も。1つにつき「特性 名前　説明」の1行）、下半分は左に「種族値」の枠（数字＋色付きのバー）、右に「技」の枠
  - 特性・種族値・技は色の枠（橙・緑・青紫）で囲み、左に縦の見出しを付ける（クリーム色の上に裸で並べると、どこに何があるか分かりにくく、空きも目立ったため）
  - 技は4つを2×2のマスに並べ、マスをタイプの色で塗る。マスの中は技名（白の太字）と「タイプ　分類 威力 N」（変化技は「変化」、追加効果・先制のある技は「＋効果」）。長い技名はマスに収まるまで文字を縮める
  - 種族値と技を同時に並べるので切り替えボタンは無い（前の「押したらすぐ決定」のカードは、1枚に両方が入り切らず切り替えが要り、文字も小さくなったため作り直した）
  - バーの色は 60未満 赤橙 / 90未満 黄 / 110未満 緑 / それ以上 水色。150 で満タン（一番高い 135 でも振り切れない）
- 時間切れのランダムは、選びかけのカードに関係なく3体から選ぶ
- CPU のドラフトはランダム（プレイヤーとは別に提示を引く）

#### 2.1.1 持ち物

- ドラフトで6体そろった直後に「持ち物」の画面をはさむ。持ち物を1個ランダムでもらい（§4.6）、6体の中の1体に持たせる
- 上に「持ち物を もらった！」と持ち物のカード（名前・説明）、下に自分の6体（絵・名前）。押したペンモンが持つ（押したらすぐ決定。見比べる情報が少ないので、ドラフトのような2段にはしない）
- 勝ち抜き戦は最初の1回だけ。チームを途中で変えない（§2.3）ので、持ち主も最後まで同じ
- 見せ合い・選出では、自分のマスにだけ持ち物名を出す。相手の持ち物は隠す（バトルで働いたときに初めて分かる）
- オンラインは15秒（`OnlineDraftSeconds`）。過ぎたら6体からランダムな1体に持たせる。持ち物の抽選は各自の端末がドラフトと同じ乱数で引く（結果は `Six` で送るので、種をそろえる必要はない）

### 2.2 見せ合い・選出

- お互いの6体を見せ合い、バトルに出す3体（ダブルスは4体）と出す順を選ぶ。ダブルスは1・2番目が最初に場に出る
- オンラインは60秒（`OnlineSelectSeconds`）。過ぎたら選びかけのぶんは残し、足りないぶんを上から埋める
- オンラインは決めた後、相手が決めるまで「相手を 待っています…」で待つ
- 押した順が出す順（1番目が先頭）。もう一度押すと外せる。「おまかせ」で残りをランダムに埋める
- CPU の選出はランダム

### 2.3 勝ち抜き戦

- 最初のドラフトで決めた6体で、負けるまで戦い続ける（途中で入れ替えはしない）
- 毎試合の前に見せ合い・選出をする。HP・状態異常は毎試合全回復
- 毎試合の前に「N戦目」と今の連勝数を出す画面をはさむ（タップで見せ合いへ）
- 7戦目・14戦目…はボス戦。ボスは固定の6体を持ち、賢さはいつも つよい（選出はランダム）
- CPU の賢さは3段階で、連勝数に応じて上がる。チームも強いペンギンが出やすくなる（§4.8）
- 勝ったら結果に連勝数を出し「次の 戦いへ」で次の試合へ（「タイトルへ」でやめてもよい）。負けたら連勝数と最高記録を出してタイトルへ
- 最高連勝数を記録する（勝つたびに保存。タイトルに表示）。シングルとダブルスは別々に数える
- ダブルスの勝ち抜き戦も、相手の強さ・ボスの流れはシングルと同じ（ボスの切り札は4体の最後に出る）

### 2.4 勝敗

- 相手の選出した3体（ダブルスは4体）を全員瀕死にしたら勝ち
- 相手が切断したら勝ち扱い（オンライン）
- 自分の通信が切れたら負け扱い（オンライン。§8.2）

## 3. ペンモン

### 3.1 データの持ち方

- 純C#の定義表（コード）で持つ。値はこの仕様書には書かない（定義表と二重管理になるため）。ゲーム内の「図鑑」で確認できる
- 1体あたりの中身: No / 名前 / ランク（§3.5）/ タイプ（1〜2個）/ 種族値6つ / 技4つ / 特性1つ。持ち物は定義表に持たない（ドラフトの後に配る。§4.6）。見た目は定義表に持たず、View が No から描く（§6）

### 3.2 能力値

- 6種: HP / 攻撃 / 防御 / 特攻 / 特防 / 素早さ
- 育成はなし。全員 Lv50 固定。個体値・努力値・性格はなく、能力値は種族値だけで決まる
- 実数値の計算式（案。個体値31・努力値0 相当）
  - HP = `種族値 + 75`
  - それ以外 = `種族値 + 20`

| ノーマル | ふつうのペンギン |

## 4. バトル

### 4.1 ターンの流れ

1. 両者が同時に行動（技4つ / 交代）を選ぶ
2. 交代が先、次に技の優先度が高い順、同じなら素早さが高い順（同速はランダム）
3. 順に行動する。瀕死になったペンモンは行動しない
4. ターン終わりの処理（毒・火傷のダメージ → 持ち物 → 特性。素早さの高い側から1体ずつ）
5. 瀕死になった側は次のペンモンを出す（控えがいなければ負け）

### 4.2 技

- 技は全ペンモンで共通の技表から選ぶ（定義表）。1体4つ固定
- 中身: 名前 / タイプ / 分類（物理・特殊・変化）/ 威力 / 命中 / 優先度 / 追加効果 / 反動 / 吸収 / 当たる回数
- PP はない（3vs3 ならほぼ気にならないため）
- 効果は「状態異常にする」「混乱させる」「ランクを変える（自分 / 相手）」「羽リレー」「回復」「天候」「守る」「追い風」「手助け」の9種類。1つの技に複数持てる
  - 回復: 自分の HP を最大HPの半分回復する（`HealMoveDenominator`）。満タンなら「しかし うまく 決まらなかった！」
  - 天候: 場を 吹雪 / 大雨 / 日差し にする（§4.10）。すでに同じ天候なら決まらない。場全体にかかるが、自分にかける技と同じく命中判定をしない
  - 羽リレー: 自分のランクの変化を引き継いで、控えの先頭（選出の順で一番前の、出せるペンモン）と交代する。控えがいなければ「しかし うまく 決まらなかった！」。交代先は選ばせない（ターンの途中で入力を待たずに済み、オンラインでもそのまま同期できるため）
  - 守る（羽でくるまる・優先度 +4）: そのターン、相手の技（攻撃技も、相手にかける変化技も）を受けない。防いだら「〇〇は 攻撃から 身を 守った！」。前のターンに守りが決まっていたら「しかし うまく 決まらなかった！」（守り続けるだけの試合にしないため。原作の「続けるほど決まりにくい」確率は、乱数を増やさないよう入れない）。全体技は守っていない相手にだけ当たる（倍率は 0.75 倍のまま）
  - 追い風（北風の号令）: 自分の陣営の素早さを 4 ターン 2 倍にする（`TailwindTurns` / `TailwindSpeedMultiplier`。始めたターンも1と数え、ターン終わりに天候の次に数える）。素早さの倍率は天候の特性の後に掛ける。吹いている間は決まらない。文「味方の / 相手の 背中に 追い風が 吹き始めた！」「〇〇の 追い風が 止んだ！」。交代しても陣営に残る
  - 手助け（声援・優先度 +5）: 隣の戦える味方の、そのターンの技のダメージを 1.5 倍にする（`HelpingHandMultiplier`。特性・持ち物の倍率と一緒に式の最後に掛ける）。味方は選ばない（狙いの画面を増やさず、§4.9 の「味方は狙えない」のままで済むため）。シングルや味方が倒れているときは決まらない。文「〇〇は 声援を 受けて 張り切っている！」
  - 守る・追い風・手助けは自分にかける技として扱い、命中判定をしない。守る・手助けはターンの終わりに消える
  - オンライン: 追い風の始まり・終わりもイベントで送り、ゲストの写しは吹いているかどうかだけ合わせる
  - 攻撃技の効果は追加効果。当たってダメージが出た後に 〇% で起きる。決まらなくても文は出さない
  - 変化技（威力 0）は効果そのもの。すでに状態異常・タイプで効かないときは「しかし うまく 決まらなかった！」、ランクが上限なら「もう 上がらない！」
  - 自分だけにかける変化技は命中判定をしない（必ず決まる）
- 優先度は +1 の先制技（滑り込み / 雪つぶて / 忍び寄り / 飛び込みジェット / 電光ジャブ）、守る（+4）・手助け（+5）と、特性 ちゃっかり の変化技だけ。技名は原作と被らないオリジナル（§1.2）
- 攻撃技の性質。数値は `BattleBalance`
  - 反動: 与えたダメージ（実際に減った HP）の 1/3 を自分も受ける（`RecoilDenominator`）。「〇〇は 反動で ダメージを 受けた！」
  - 吸収: 与えたダメージの半分を回復する（`DrainDenominator`）。HP が満タンなら何も出さない。「〇〇は 体力を 吸い取った！」
  - 連続: 2〜5回当たる（2・3回 35%、4・5回 15%。原作と同じ `MultiHitPercents`）か、決まった回数（2回）当たる。命中は最初に1回だけ判定し、1回ずつ急所・乱数を引く。相手が倒れたらそこで止める。最後に「N回 当たった！」。相性の文は1回目だけ出す（毎回出るとくどいため）
  - 連続技は1回ごとに受けた側の特性（とげとげ肌など）が起きる。踏ん張りマフラーは HP 満タンのときしか効かないので、1回目で残っても次で倒れる
  - 反動・吸収・連続の技はふつうの攻撃技なので、追加効果も持てる（炎の突進は 10% で火傷 など）

### 4.3 ダメージ

ポケモンと同じ式を使う（Lv50）。

```text
ダメージ = ((22 × 威力 × 攻撃 ÷ 防御) ÷ 50 + 2)
          × 急所(1.5) × 乱数(0.85〜1.00) × タイプ一致(1.5) × 相性 × 火傷(物理なら0.5)
```

- 計算は式の左から順に掛け、掛けるたびに小数を切り捨てる。相性が 0 でなければ最低 1 ダメージ
- 物理技は 攻撃 / 防御、特殊技は 特攻 / 特防 を使う
- 急所は 1/24。急所のときは自分の下がった攻撃ランクと相手の上がった防御ランクを無視する
- 命中は「技の命中 × 命中ランク ÷ 回避ランク」。原作と同じく（自分の命中ランク − 相手の回避ランク）を -6〜+6 に収めた1つの倍率で掛ける
- 乱数は `System.Random`（オンラインはホストの乱数だけを使う）

### 4.4 状態異常

| 状態 | 効果（原作に準拠） |
| --- | --- |
| 麻痺 | 素早さ半分、1/4で動けない |
| 毒 | ターン終わりに最大HPの1/8 |
| 猛毒 | ターン終わりに 1/16, 2/16, 3/16…と増える |
| 火傷 | ターン終わりに 1/16、物理のダメージ半分 |
| 眠り | 1〜3ターン動けない。その次のターンに目を覚まして、そのまま動ける |
| 氷 | 1/5で解ける（解けたターンは動ける）。火タイプの技を受けると解ける |
| 混乱 | 1〜4回、技を出す前に 1/3 で自分を攻撃（威力40の物理・タイプなし）。交代で治る |

- 麻痺・毒・猛毒・火傷・眠り・氷は1体に1つだけ。交代しても残る（猛毒のダメージの段階だけは交代で 1/16 に戻る）
- 混乱は別枠なので、状態異常と重なる
- タイプで効かない: 火 は 火傷、氷 は 氷、雷 は 麻痺 にならない
- 技を出す前の判定は 眠り・氷 → 混乱 → 麻痺 の順
- ターン終わりのダメージは 素早さの高い側から（同速は自分側から）。ダメージは最低 1
- 状態異常の印（色付きの札）を名前の枠に出す。混乱はピンクの「混乱」の札を状態異常の印の右に出し、治るか交代で消す
- 名前は一般名詞なので原作と同じ漢字（麻痺・毒など）を使う

### 4.5 能力変化（ランク）

- 攻撃〜素早さ・命中・回避が -6〜+6
- 倍率は原作どおり（2/8 〜 8/2、命中・回避は 3/9 〜 9/3）
- 交代すると元に戻る
- 上がった / 下がった量で「ぐーんと」「がくっと」が付く。上がると青、下がると赤にペンモンが光る
- 名前の枠には、上がった能力があれば青の ▲、下がった能力があれば赤の ▼ だけを出す（両方なら ▲▼）。自分側は状態異常の印の右、相手側は HP バーの下の行。段数を枠に並べると状態異常の印と被り、枠も狭いため
- 段数は名前の枠をタップして開く一覧で見る（原作のバトル情報画面と同じ形）。7つの能力ごとに ▲（下がったら ▼）を6つ並べ、変わった数だけ色を付け、右に +2 / -1 / ±0 を出す。暗幕ごとボタンなので、どこをタップしても閉じる。そのペンモンが場から消えたら閉じる
- オンラインのゲストも、写しにランクを入れて同じ一覧を見られる。羽リレーで引き継いだランクは、文を出さないイベント（StagesPassed。Amount に7つを 4bit ずつ詰める）で送る

### 4.6 特性・持ち物

- 特性はペンモンごとに1つ固定。どのペンモンが何を持つかは定義表 `MonsterTable` が正（図鑑で確認できる）
- 持ち物は定義表に持たない。ドラフトで6体そろった後に **1チーム1個** を候補から等確率で引き（`ItemDraw`）、6体の中の1体に持たせる
  - 候補: 下の表のうち ヒナの綿毛 を除く12個（`BattleBalance.UndrawableItems` で外す）。お天気石は天候の特性がいないと何も起きないが、運の面白さとして残す
  - 勝ち抜き戦の CPU: 6体からランダムな1体に持たせる。ボス: 切り札（伝説）に持たせる。相手ごとに引き直す
  - プレイヤー: 持ち物の画面（§2.1.1）で好きな1体に持たせる（オンラインも同じ）
- ヒナの綿毛は持ち物ではなく、ランク「ヒナ」全員にいつも働く補正（図鑑・ドラフトのカードに「ヒナ ヒナの綿毛」の行を出す）
- 特性はドラフトのカードと図鑑、バトルの交代の画面（自分の子だけ。§7）に名前と短い説明を出す（持ち物は持っているときだけ出す）
- バトルでは、特性が働くたびに **特性の帯**（「〇〇の / 強面」）を出す（§7）。原作の特性パネルと同じく、どの特性が何をしたかを続きの演出と並べて見せるため。帯は文の代わりなので「〇〇の 強面！」の文は出さず、効果の文（「相手の 攻撃が 下がった！」など）はそのまま出す
  - いつ出すか: 下の表の「いつ」に働いたとき。ダメージの倍率の特性は、倍率が1以外になった攻撃でダメージの前に出す（使った側は1回の技で1回、受けた側は1体につき1回。連続技で毎回出さない）。硬い羽は急所を防いだとき、石頭は反動を受けなかったとき、連打名人は2〜5回の技を使ったとき、夜更かしは眠りを防いだとき（「うまく 決まらなかった」の前）、ひねくれ者は向きが変わる前、ちゃっかりは変化技の技名の前、ひと休みは HP が減っていて「戻れ！」の前、雪滑り・波乗り・光合成は天候が始まったときと、その天候の中へ出てきたとき
  - 何も起きないときは出さない（仇討ちで倒れた味方がいない、ひと休みで満タン、など）
- ダメージの倍率は、原作の「その他の補正」と同じく式の最後（火傷の後）に掛けて切り捨てる
- 「1回だけ」の持ち物は使うとそのバトル中は無くなる（交代しても戻らない。試合ごとに戻る）
- 数値は `BattleBalance`（`IntimidateStages` / `LastStandMultiplier` / `FeatherMultiplier` / `TechnicianMultiplier` など）

| 気まぐれ | 攻撃〜素早さのうち、まだ上がる1つが2段上がり、それ以外でまだ下がる1つが1段下がる（命中・回避は動かさない。運だけの試合を増やさないため） | ターン終わり |
| ちゃっかり | 変化技の優先度 +1 | 行動順 |
| まっさら | HP が満タンのとき、受けるダメージ半分（連続技は1発目だけ） | ダメージ計算 |

| 持ち物 | 効果 | いつ |
| --- | --- | --- |
| 干し魚 | 最大HPの 1/16 回復 | ターン終わり |
| おやつのイカ | HP が半分以下になったら最大HPの 1/4 回復（1回だけ） | HP が減ったとき |
| さっぱり昆布 | 状態異常になったらすぐ治す（1回だけ。混乱は治さない） | 状態異常になったとき |
| 勇気の羽 | 物理技のダメージ 1.2 倍 | ダメージ計算 |
| 賢い羽 | 特殊技のダメージ 1.2 倍 | ダメージ計算 |
| 命のつらら | 攻撃技のダメージ 1.3 倍。当てるたびに自分の最大HPの 1/10 減る | ダメージ計算 / 攻撃したあと |
| 目利きメガネ | 抜群の技のダメージ 1.2 倍 | ダメージ計算 |
| 踏ん張りマフラー | HP 満タンのとき、たおれる攻撃を受けても HP1 で残る（1回だけ） | 攻撃を受けたとき |
| 軽い羽 | 素早さ 1.2 倍（麻痺の後に掛ける） | 行動順 |
| 雪のコート | 抜群の技で受けるダメージ 0.75 倍 | ダメージ計算 |
| お天気石 | 自分が始めた天候が 8 ターン続く（ふつうは 5） | 天候を始めたとき |
| 貝の首飾り | 攻撃技で与えたダメージの 1/8 回復（全体技は合計から1回） | 攻撃したあと |

- 攻撃のあとの順: ダメージ（連続技は回数ぶん）→ 氷が解ける → 吸収・反動 → 技の追加効果 → 勢いづく → 受けた側の特性（物理のとき）→ 命のつらら → 貝の首飾り
- ヒナの綿毛（ランク「ヒナ」の補正）: 防御・特防 1.5 倍。ダメージ計算で能力値に掛ける（能力変化ではないので急所でも消えない）
- 素早さの倍率の順: ランク → 麻痺 → 軽い羽 → 天候の特性
- 文の例: 帯「〇〇の / 強面」→ 効果の文 / 「〇〇は 干し魚で HPを 回復した！」/「〇〇は 踏ん張りマフラーで 持ちこたえた！」

### 4.7 オンラインの制限時間

- 1ターン30秒（`OnlineTurnSeconds`）。過ぎたら一番上の技を自動で使う。ダブルスは場の1体ごとに30秒（狙いは相手の左。倒れていれば右）
- 瀕死の後の入れ替えも30秒。過ぎたら出せる中で一番上のペンモンを出す
- 残り秒数は画面の上に「残り N 秒」と出す（ドラフト・選出は右上の「やめる」の左）。CPU 戦では出さない

### 4.8 CPU

| 賢さ | 行動 |
| --- | --- |
| よわい | 技をランダムに選ぶ。瀕死の後は控えの先頭を出す |
| ふつう | 一番ダメージが出る技を選ぶ（乱数なし・急所なしで計算し、命中率を掛けた見込み。連続技は平均の回数 3.1（連打名人なら 5）を掛ける。変化技は 0 とみなし、全部 0 ならランダム）。ただし先に、HP が半分以下なら回復の技、HP が満タン（出てすぐ）でまだその天候でなければ天候の技を使う |
| つよい | ふつう ＋ 不利なら交代する。瀕死の後は相性のいいペンモンを出す |

- 「不利」= 相手の攻撃技に 抜群 を取られていて、こちらの攻撃技はどれも 抜群 を取れないとき。タイプ相性だけで見る
- 交代先は「こちらの通りやすさ − 相手の通りやすさ」（攻撃技の一番いい相性の倍率どうしの差）が今より大きく、自分も不利でないペンモン。いなければ交代しない
- 勝ち抜き戦での切り替え（案）: 1〜3戦目 よわい / 4〜6戦目 ふつう / 7戦目から つよい。ボスはいつも つよい
- チームの強さ（案）: CPU のドラフトで、連勝数 × 10%（最大 100%）の確率で提示のうち種族値の合計が一番高いのを取る（それ以外はランダム）。50 体からはランク（§3.5）で合計に差があるので、連勝するほどエース・伝説を取りやすくなる（伝説は1チーム1体まで）
- 数値は `BattleBalance`（`NormalCpuFromWins` / `StrongCpuFromWins` / `BossInterval` / `CpuStrongPickPercentPerWin`）

### 4.9 ダブルス（案）

場に2体ずつ出して戦うルール。ポケモンのダブルバトルを、技の範囲と行動順だけに絞って入れる。

| 項目 | 内容 |
| --- | --- |
| 選出 | ドラフトの6体から4体（`DoublesPartySize`）。選出の1・2番目が最初に場に出る |
| 場 | 1陣営に2つ（`DoublesActiveCount`）。0 が左・1 が右 |
| 行動 | 場の1体ずつ「技 / 交代」を選ぶ。左から順に選び、1体目の行動は決めたら戻せない |
| 対象 | 1体に当たる技は狙う相手を選ぶ（相手が1体しか残っていなければ選ばない）。狙った相手が先に倒れていたら、もう片方に当たる。味方は狙えない |
| 全体技 | 「相手 全員に 当たる」技は場の相手全員に当たる。2体に当たったらダメージ 0.75 倍（`SpreadMultiplier`。特性・持ち物の倍率と一緒に式の最後に掛ける）。命中・急所・追加効果は相手ごとに判定する。自分にかかる追加効果・命のつららの反動は1回だけ |
| 行動順 | 場の4体の行動をまとめて §4.1 と同じ順（交代 → 優先度 → 素早さ）に並べる |
| 場に出たとき・ターン終わり | 場の4体を素早さの高い順に（同速は 陣営 0 → 1、場の左から） |
| 交代 | 2体が同じ控えを選ぶことはできない（画面で選べなくする） |
| 瀕死 | ターンの後、空いた場を左から控えで埋める。控えが足りなければ空いたまま、残りの1体で戦う |
| 勝敗 | 選出の4体が全員瀕死になったら負け |

- 全体技は、広がるイメージの技に付ける（大波・吹雪ブレス・冷たい息・泡吐き・噴火ブラスト・叫び声・ぐるぐる風・ごろごろ落とし・オーロラウェーブ・海神の大渦・放電スパーク・胞子ばらまき・砂けむり）。どの技かは技表 `MoveTable` が正（図鑑の効果に「相手 全員に 当たる」と出る）
- 特性: 強面は場の相手全員の攻撃を下げる。仇討ちは選出の味方の瀕死を数える（シングルと同じ）
- 羽リレーは使った場に控えの先頭が出る
- 外れたときの文は、どちらに外れたか分かるよう「しかし 〇〇には 当たらなかった！」にする（シングルも同じ文）
- CPU: 狙いは見込みダメージが一番大きい相手（全体技は当たる相手全員の合計で比べる）。よわい は技も狙いもランダム。つよい の交代は向かいの相手（同じ番号の場。倒れていればもう片方）との相性で決める

### 4.10 天候

場全体に1つだけかかる状態。技か特性で始まり、数ターンで止む。天候に乗る特性を持つ子と組ませると強い、という編成の軸にする。

| 天候 | 効果 | 始める技 / 特性 |
| --- | --- | --- |
| 吹雪 | ターン終わりに、氷タイプ以外は最大HPの 1/16 のダメージ（雪雲呼び・雪滑りの子は受けない）。氷タイプは物理技を受けるときの防御 1.5 倍 | 雪乞い / 雪雲呼び |
| 大雨 | 海の技 1.5 倍、火の技 0.5 倍 | 雨乞い踊り / 雨呼び |
| 日差し | 火の技 1.5 倍、海の技 0.5 倍 | 日向ぼっこ / 日照り |

- 続くのは 5 ターン（`WeatherTurns`）。お天気石を持った子が始めると 8 ターン（`WeatherStoneTurns`）。始めたターンも1と数える
- 新しい天候は今の天候を上書きする。同じ天候は始められない（技なら「うまく 決まらなかった」、特性なら何も出さない）
- 場に出たときの特性は素早さの高い順に働くので、両方が天候を呼ぶと遅い側の天候が残る
- ターン終わりの最初に残りを数え、0 になったら「吹雪が 止んだ！」などを出す（止んだターンは吹雪のダメージもない）。続いていれば、1体ずつ 吹雪のダメージ → 毒・火傷 → 持ち物 → 特性 の順
- 天候のダメージの倍率は、特性・持ち物の倍率と一緒に式の最後に掛ける
- 文: 「吹雪が 吹き始めた！」「大雨が 降り始めた！」「日差しが 強くなった！」/ 止んだら「吹雪が 止んだ！」「雨が 上がった！」「日差しが 元に 戻った！」/ 吹雪のダメージは「〇〇は 吹雪に 打たれている！」
- 数値は `BattleBalance`（`WeatherBoostMultiplier` / `WeatherWeakenMultiplier` / `SnowDamageDenominator` / `SnowIceDefenseMultiplier` / `WeatherSpeedMultiplier`）
- オンライン: 天候の始まり・終わりもイベントで送り、ゲストの写しは天候の種類だけ合わせる（残りターンはホストが数える）
- 試合が終わったら天候は消える（勝ち抜き戦の次の試合には持ち越さない）

- 育成・収集はない。記録は勝ち抜き戦の最高連勝数だけ

## 6. 画面・ビジュアル

- 横画面固定（Android / Windows / ブラウザ）
- 画面の基準は 1920x1080。比率の違う画面（20:9 のスマホ、4:3 のタブレットなど）では足りない側を広げ、基準の 1920x1080 は必ず全部見えるようにする（CanvasScaler の Expand）。なので枠やボタンは 1920x1080 の内側に、端から少し余白を空けて置く
- スマホのカメラ穴・角丸を避ける: 背景色は画面の端まで塗り、文字・ボタン・表はセーフエリア（Screen.safeArea）の内側に置く。いまはタイトルと、タイトルから開く画面（図鑑・タイプ相性表・遊び方・設定）と、ドラフト画面と、ドラフト〜バトルの「やめる」が対象。バトルのメッセージ窓は画面の端から端まであるので、文字の左右の余白を広め（100）にしてカメラ穴を避ける
- バトル画面はダイヤモンド・パール風: 手前左に自分（後ろ姿）、奥右に相手（正面）。HPバーと名前の枠、下にメッセージ窓とコマンド
- ペンモンの絵はコードで生成するドット絵。1体につき正面と後ろの2枚（64x64）。実行時に No ごとのデザインから作る
- ポケモンのように1体ずつシルエットから描き分ける（共通の胴体＋小物では全員同じ形に見えたため）。タイプのイメージ（§3.3）を形にする。例: シャチペンは横長で背びれ、イワペンは岩を背負う、カザンペンは体が火山、アラシペンは体が雲
- 全員に共通させるのは「ペンギンの顔」だけ: 白い顔、オレンジのくちばし、ピンクのほっぺ。大きな黒目は怖く見えたので使わない
- 正面立ちばかりにしない（全員が直立だと色違いに見えたため）。1体ずつ性格を決め、姿勢・体型・重心・ヒレの位置・目で表す。例: ユキペンは前のめりに跳ねる、イワペンは低く前かがみ、モフペンは寝そべる、ナキムシペンは体を丸めて目をそらす
  - 黒いシルエットだけで見分けられることを目標にする。飾りや色だけで差を付けず、まず体の形を変える
  - 正面の絵は基本、左（手前の自分側）を向いた斜め向きにする。後ろ姿は反転なので右（相手側）を向く
- 目は9種類から1体ずつ選ぶ（全員同じ目だと同じ顔に見えたため）。同じ目が全体の1/4を超えないようにする。どの子がどの目かは `PenguinDesigns` が正

| 目 | 形 | 主に使う子 |
| --- | --- | --- |
| 点目 | 2x2 の黒 | ゆるい・素朴な子 |
| 丸目 | 2x3 の黒に光1ドット | 主役っぽい子 |
| にっこり目 | ^ ^ | 陽気な子 |
| ねむそう目 | 上が平らな半目 | のんびり・夜の子 |
| キリッ目 | 上の辺が顔の内側へ下がる | 強そうな子・エース |
| きらきら目 | 3x3 の黒に光2ドット | ヒナ |
| 星目 | 黒の十字 | 不思議な子（オーロラ・手品） |
| 糸目 | 横1列の黒 | 落ち着いた子・伝説 |
| こまり目 | キリッ目の上下逆（内側が上がる） | 臆病な子・泣き虫 |

- ランクでシルエットの大きさと飾りを変え、図鑑やドラフトで絵だけでもランクが分かるようにする（§3.5）
  - ヒナ: 体を小さく（ふつうの6割ほど）描き、頭に綿毛のアホ毛を立てる
  - エース: 背びれ・翼・角など大きな武器を付ける
  - 伝説: キャンバスいっぱいに描き、金の飾り（王冠・角・輪）を付ける。輪郭の外にもう1周、金の縁取りを足して光って見せる
- 後ろ姿は正面と同じ形で、顔とおなかの白を塗らず、左右を反転する（自分側は右の相手のほうを向く）
- 定義表にない No はふつうのペンギン（ペンタ）の絵で代用する
- 背景は空（上ほど濃い青）と地面（緑）。ペンモンは楕円の台座の上に立つ
- 名前の枠: 名前・タイプ・Lv50・HPバー・状態異常の印・ランクの印（▲▼。タップで一覧。§4.5）。HPバーは 50% 以下で黄、20% 以下で赤。数字は自分側だけ出す
- 残りの数はバトルの場には出さない（タマゴの列を置いたら、どこに置いてもペンモンの絵や枠にかぶって見づらかったため）。残りは「ペンモン」の交代の画面で見る
- 繰り出すときに投げるタマゴ（§7）の種類（`EggKind`）は陣営ごとに持てる。いまはシングル・ダブルスとも「ふつう」だけ。色は View の `EggStyleTable`。見た目だけなのでオンラインでは送らない
- アプリアイコン: 主役の No.1 ユキペンの正面の絵を、空と雪原の背景に乗せたドット絵。`Tools > PenguinMonster > App Icon` で生成して Player Settings に設定する（Windows・Android は全サイズ、ブラウザは WebGL テンプレートの favicon）
  - Android のアダプティブアイコンは背景と前景に分け、前景のペンギンは中央の安全域（108 のうち 66）に収めて、丸や角丸に切られても欠けないようにする

## 7. UI・演出・サウンド

- フォントは全プラットフォームで丸ゴシックの M PLUS Rounded 1c Medium（OFL。`Common/Resources/Fonts/`）。Unity 標準フォントのままだとスマホは端末の細い字、ブラウザは日本語が出ないため、実行時に全 Text を差し替える（GameFontApplier）。太字の指定はこのフォントを太らせて出す。行の高さが文字の約1.45倍と高く、枠ぎりぎりの Text が丸ごと消えたので、差し替えた Text は縦にはみ出しても出す（自動で縮める Text は除く）
  - そのぶん字が大きく、長い名前（ムテッポウヒナペン）や2タイプ（ノーマル/オーロラ）で隣の文字と重なりやすい。名前・特性・技の一覧など中身が変わる Text は、枠に入り切らないときだけ地の文字と `<size>` を同じ割合で縮めて入れる（TextFit。最小で半分）。名前のように1行で見せたいものは折り返さず横幅で、特性や技の一覧のように折り返すものは高さで判定する。名前の枠の Lv は右端に専用の幅を取り、名前はその手前で止める
- 表記は漢字まじり（ひらがなだけだと読みにくいため）。文・ボタン・技名・タイプ名・特性名・持ち物名・状態異常名に漢字を使い、語の区切りの空白は原作どおり残す。ペンモンの名前とカタカナ語はそのまま
- メッセージは「効果は 抜群だ！」のような一文ずつの送り表示（速さは設定で変えられる）。文字を1つずつ出し、送り中のタップで全文、読み終わったら▼を出してタップで次へ（窓の外の場をタップしてもよい）
- 「行けっ！」「〇〇の △△！」「戻れ！」の文はタップを待たず、そのまま登場・攻撃の演出へつなげる
- ドラフト〜バトルの間（持ち物の画面も。勝ち抜き戦は「N戦目」の画面も）は、右上に「やめる」を出す。押すと「戦いを やめますか？」の確認（やめる / 続ける）を出し、やめるでタイトルへ戻る。結果の画面では出さない
  - 勝ち抜き戦: その回はおしまい（途中経過は保存しない §9）。最高連勝数は勝つたびに保存しているので残る
  - オンライン: 部屋を抜けるので、相手には「相手が 切断しました」が出て相手の勝ち（§8）。確認を出している間も制限時間は進む
  - 左上はバトルで相手の名前の枠があるので右上に置く。ドラフト・選出の残り秒数は「やめる」の左に出す
- コマンドは「戦う / ペンモン」の2つ（逃げるは無い）。戦う → 技4つ（タイプの色付き）＋戻る
  - ダブルスで1体に当たる技を選んだら、下の窓に相手の左右2つのボタン（名前と相性）＋戻る を出して狙いを選ぶ
  - ダブルスの技ボタンの相性は、相手2体で同じときだけ出す（違うときは狙いを選ぶ窓で1体ずつ見せる）
- ダブルスの場: ダイパと同じく1つの台座に2体を左右に並べ、絵を一回り小さくする（相手 4倍・自分 6倍）。名前の枠は縦に2つ重ねる（相手は左上、自分は右）
  - 技ボタンには今の相手への相性を出す: 「抜群！」（赤）/「今ひとつ」/「効果なし」。等倍と変化技は何も出さない
  - 追加効果・先制のある技は「＋効果」と付ける
  - 技ボタンを長押し（マウスは乗せる）すると、窓の上に説明（名前・タイプ / 分類・威力・命中 / 効果）を出す。長押しで見たときは、離しても技を出さない
- ペンモン（交代の画面）: 1体1枠で「絵・名前・HP（戦闘中 / 瀕死 / 交代先）・状態異常」と、その下に小さく「特性 名前」
  - 枠を長押し（マウスは乗せる）すると、一覧の右に自分の子の特性・持ち物の説明（ドラフトと同じ文。ヒナは綿毛も。使った持ち物は「（使った）」）を出す。技ボタンと同じく、長押しで見たときは離しても交代しない。戦闘中・瀕死の子も見られる
  - 相手の特性は見せない（原作と同じく、働いて特性の帯が出るまで分からないのを読み合いにするため）

## 8. オンライン

- 参加コードを共有して離れた2人が1対1で対戦する（ランダムマッチはしない）
- タイトルの「オンライン対戦」→ 部屋を作る / コードで参加 → シングル / ダブルス → ドラフト → 持ち物 → 見せ合い・選出 → バトル → 結果 → タイトル（1試合ごとに部屋を作り直す。再戦ボタンはない）
  - シングル / ダブルスはホストが接続の後に選ぶ。ゲストはその間「相手が ルールを 選んでいます…」で待つ
- 接続は共通基盤（`OnlineSession` / `ModeSelectPanel`）を使う。ModeSelectPanel の「CPUと対戦」は隠す（CPU 戦はタイトルの勝ち抜き戦から入る）。見た目はゲーム側（SceneBuilder の .Room.cs）で作り直し、左に「部屋を 作る」・右に「コードで 参加」の枠、待つ間は大きな枠に参加コードを出す
- ホストだけがバトルとドラフトの抽選を計算し、ゲストは選んだ行動を送って結果を表示する
  - ドラフトはホストが決めた種でゲストの端末が引く（§2.1）
  - バトルはホストが陣営 0、ゲストが陣営 1。ゲストはホストから届いた `BattleEvent` で写しの状態（HP・状態異常・場・勝敗）を更新して再生する
  - ゲストの画面では自分が手前になるよう、写しの陣営を入れ替えて持つ
- 相手が切断したら（ドラフト中・持ち物の画面・選出中も含む）「相手が 切断しました」を表示して勝ち扱い。決着の後の切断は無視する
- 自分の通信が切れたら「通信が 切れました」を表示して負け扱い（§8.2）
- オンライン対戦の勝敗は記録しない

### 8.1 メッセージ一覧

1つの名前付きメッセージ（`penmon.link`）に「種類・int の個数・int の列」を載せて送る。確実に順番どおり届く送り方（ReliableFragmentedSequenced）を使う。届いたものは種類ごとに貯め、待つ側が取り出す。

| 種類 | 向き | 中身 | いつ |
| --- | --- | --- | --- |
| DraftSeed | ホスト → ゲスト | ゲストのドラフトの種・ルール（0 = シングル / 1 = ダブルス） | ホストがルールを選んだら |
| Six | お互い | ドラフトで取った6体（1体 2 int: No・持ち物） | 持ち物を持たせたら |
| Team | お互い | 選出した3体（ダブルスは4体）（1体 2 int: No・持ち物。並びが出す順） | 選出を決めたら |
| Action | ゲスト → ホスト | 場の順の行動（1個 3 int: 0 = 技 / 1 = 交代, 技の番号 or 選出の何番目か, 狙う相手の場） | 毎ターン |
| Replace | ゲスト → ホスト | 瀕死の後に出すペンモン（「場の番号・選出の何番目か」の組を空いた場の数だけ） | ゲストのペンモンが瀕死になったら |
| Events | ホスト → ゲスト | `BattleEvent` の列（1個 9 int: 種類・陣営・選出の何番目か・技の番号・HP・状態異常・能力・量・場の番号） | バトル開始・毎ターン・瀕死の入れ替え |

- 瀕死の入れ替えは、両方瀕死ならホストが両方そろうのを待ち、まとめて1回の Events で送る
- 陣営はホストから見た番号で送り、ゲストが受け取るときに入れ替える
- 持ち物は定義表に無い（ドラフトの後に配る）ので、ペンモンは No と持ち物の組で送る。見せ合いで相手の持ち物を隠すのは表示側だけで行う

### 8.2 通信切れの扱い

- Relay は約10秒通信が無いと切断する。スマホでアプリを裏に回す（チャットでコードを送りに行く・通知・電源ボタン）、ブラウザのタブを隠すと、Unity ごと止まって通信も止まる
  - 部屋を作った後の待機画面に「コードを送ったら すぐ戻ってきてください」と出す
  - フレームが10秒以上止まっていたら（壁時計で測る）、戻ってきた時点で部屋を抜ける（`OnlineSession.OnConnectionLost`）。待機画面では「接続が切れました」、試合中は「通信が 切れました」で負け扱い。相手には切断が届いて勝ち扱いになる
  - Windows 版は裏でも動き続けるので、ウィンドウを切り替えても切れない
- 相手が落ちたと気づくまでの時間（`UnityTransport.DisconnectTimeoutMS`）は10秒（既定の30秒だと固まったように見えるため）
- バトル中に相手の返事（Action / Replace / Events）を180秒（`OnlineReplyTimeoutSeconds`）待っても届かなければ、通信が止まったとみなして「通信が 切れました」で負け扱いにし、部屋を抜ける
  - ホストとゲストは別々の状態から「次に何を待つか」を決めるので、状態がずれると接続は生きたまま待ち合って止まる。その保険。両方が同時に止まっていた場合は、両方とも負けになることがある
  - ルール選び（DraftSeed）・ドラフト・選出の待ちには付けない（状態のずれが起きないため。相手が操作しないまま止まっているときは「やめる」で抜けられる）

## 9. セーブ

- 勝ち抜き戦の最高連勝数（シングル・ダブルス別）、設定（音量・メッセージの速さ）
- 音量は共通基盤の `AudioManager` が保存する（設定画面を閉じたとき）。メッセージの速さは `GameSettings`（PlayerPrefs）に、押したときに保存する
- 最高連勝数は共通基盤の `BestScore`（PlayerPrefs）に保存する。勝つたびに更新するので、途中でやめても記録は残る。キーはシングルが `PenguinMonster.SurvivalWins`（ダブルス追加前と同じ）、ダブルスが `PenguinMonster.SurvivalWins.Double`
- 勝ち抜き戦の途中経過は保存しない（案）。1回が短めなのと、6体と連勝数を復元する手間に見合わないため。アプリを閉じたらその回はおしまい
