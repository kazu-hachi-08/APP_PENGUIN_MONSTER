# ペンモン 仕様書

> 対話で中身を決めながら埋めていく。未定の項目は「未定」と書いておく。「（案）」は Claude の提案で、まだ確認していないもの。

## 1. 概要

ペンギンだけのモンスターをドラフトで集めて戦う、ターン制の対戦ゲーム。見た目と手触りはダイヤモンド・パール風の2D。ストーリーやフィールド探索はない。

| 項目 | 内容 |
| --- | --- |
| アプリ名 | ペンモン |
| ジャンル | ターン制モンスター対戦（3vs3 シングル。ダブルスは後で追加） |
| グラフィック | 2Dドット絵（ペンギンは1体ずつのデザインをコードで生成） |
| プレイ人数 | 1人（勝ち抜き戦・CPU戦）/ 2人（オンライン・参加コード） |
| 1試合の長さ | 5〜10分が目安 |
| ペンモンの数 | 最初 24 体 → 50 → 75 → 100 体と段階的に増やす |
| プラットフォーム | Android / Windows / ブラウザ（WebGL）。横画面固定 |

### 1.1 モード

| モード | 編成 | 相手 | ゴール |
| --- | --- | --- | --- |
| 勝ち抜き戦（1人） | 最初にドラフトで6体。最後まで同じチーム | CPU（勝つほど強くなる） | 何連勝できるか。7戦ごとにボス |
| オンライン対戦（2人） | 毎回ドラフトで6体 | 友達（参加コードで接続） | 相手の3体を全員たおす |

### 1.2 権利まわりの方針

ゲームの仕組み（タイプ相性・種族値・ダメージ式など）はポケモンを参考にするが、タイプ名・技名・特性名・持ち物名・見た目はすべてオリジナルにする。

## 2. ゲームの流れ

```text
タイトル
 ├ 勝ち抜き戦 → ドラフト → [見せ合い → 選出 → バトル → 結果] をくり返す（負けたら終わり）
 ├ オンライン対戦 → 部屋を作る / コードで参加 → ドラフト → 見せ合い → 選出 → バトル → 結果
 ├ ずかん
 ├ タイプ相性表
 ├ あそびかた
 └ 設定
```

### 2.0 タイトルから開く画面

どれも左上の「もどる」でタイトルへ戻る。

- ずかん: 上の帯でタイプをしぼりこむ（すべて + 10タイプ。2タイプのペンモンはどちらでも出る）。左の一覧で押したペンモンの 絵・No・名前・タイプ・種族値・特性と持ち物（説明つき）・技4つ（タイプ・分類・威力・命中・先制・効果）を右に出す
- タイプ相性表: §3.4 の表をそのまま出す（2 は赤・½ は青・0 は灰。等倍は空欄）
- あそびかた: タブで ドラフト / せんしゅつ / バトル / かちぬきせん を切り替える。文面は `HowToPanel` が持つ（ルールを変えたら合わせて直す）
- 設定: BGM・効果音の音量（スライダー）、メッセージの速さ（おそい 0.5倍 / ふつう / はやい 2倍）

### 2.1 ドラフト

- ランダムな3体から1体を選ぶ×6回で6体そろえる
- 提示はプレイヤーごとに別々。相手と同じペンギンを取ってもよい。自分がすでに取ったペンギンは出ない
- 候補は全ペンモンから純ランダム（タイプの偏りの補正はしない）
- オンラインは1回15秒。過ぎたら3体からランダム
- オンラインの抽選: ホストが種（seed）を決めてゲストへ送り、ゲストの端末はその種で自分の提示を引く（提示はお互い別々で、相手の取り方に左右されないため）
- 提示数（3）・回数（6）・制限時間（15秒）はバランス定義クラスに置く（`DraftOfferCount` / `DraftRounds` / `OnlineDraftSeconds`）
- 提示の3枚には絵・名前・タイプ・種族値（と合計）を出す。押したらすぐ決定
- CPU のドラフトはランダム（プレイヤーとは別に提示を引く）

### 2.2 見せ合い・選出

- お互いの6体を見せ合い、バトルに出す3体と先頭を選ぶ
- オンラインは60秒（`OnlineSelectSeconds`）。過ぎたら選びかけのぶんは残し、足りないぶんを上から埋める
- オンラインは決めた後、相手が決めるまで「あいてを まっています…」で待つ
- 押した順が出す順（1番目が先頭）。もう一度押すと外せる。「おまかせ」で残りをランダムに埋める
- CPU の選出はランダム

### 2.3 勝ち抜き戦

- 最初のドラフトで決めた6体で、負けるまで戦い続ける（途中で入れ替えはしない）
- 毎試合の前に見せ合い・選出をする。HP・状態異常は毎試合全回復
- 毎試合の前に「Nせんめ」と今の連勝数を出す画面をはさむ（タップで見せ合いへ）
- 7戦目・14戦目…はボス戦。ボスは固定の6体を持ち、賢さはいつも つよい（選出はランダム）
- CPU の賢さは3段階で、連勝数に応じて上がる。チームも強いペンギンが出やすくなる（§4.8）
- 勝ったら結果に連勝数を出し「つぎの たたかいへ」で次の試合へ（「タイトルへ」でやめてもよい）。負けたら連勝数と最高記録を出してタイトルへ
- 最高連勝数を記録する（勝つたびに保存。タイトルに表示）

#### ボス（案）

| 戦数 | 名前 | セリフ | チーム（No） |
| --- | --- | --- | --- |
| 7 | ひょうざんの ユキオ | この こおりの かべを こえられるかな？ | こおり中心（1, 7, 8, 9, 10, 12） |

- 人物の絵はまだ無いので、登場画面は背景を赤くして、名前・セリフと先頭のペンモン（正面）を「ぽよん」と出す
- チームの中身は定義表 `BossTable` が正。体数が増えたら（Phase 9）見直す

### 2.4 勝敗

- 相手の場に出た3体を全員ひんしにしたら勝ち
- 相手が切断したら勝ち扱い（オンライン）

## 3. ペンモン

### 3.1 データの持ち方

- 純C#の定義表（コード）で持つ。値はこの仕様書には書かない（定義表と二重管理になるため）。ゲーム内の「ずかん」で確認できる
- 1体あたりの中身: No / 名前 / タイプ（1〜2個）/ 種族値6つ / 技4つ / 特性1つ / 持ち物1つ。見た目は定義表に持たず、View が No から描く（§6）

### 3.2 能力値

- 6種: HP / こうげき / ぼうぎょ / とくこう / とくぼう / すばやさ
- 育成はなし。全員 Lv50 固定。個体値・努力値・性格はなく、能力値は種族値だけで決まる
- 実数値の計算式（案。個体値31・努力値0 相当）
  - HP = `種族値 + 75`
  - それ以外 = `種族値 + 20`

## 4. バトル

### 4.1 ターンの流れ

1. 両者が同時に行動（技4つ / 交代）を選ぶ
2. 交代が先、次に技の優先度が高い順、同じならすばやさが高い順（同速はランダム）
3. 順に行動する。ひんしになったペンモンは行動しない
4. ターン終わりの処理（どく・やけどのダメージ → 持ち物 → 特性。すばやさの高い側から1体ずつ）
5. ひんしになった側は次のペンモンを出す（控えがいなければ負け）

### 4.2 技

- 技は全ペンモンで共通の技表から選ぶ（定義表）。1体4つ固定
- 中身: 名前 / タイプ / 分類（物理・特殊・変化）/ 威力 / 命中 / 優先度 / 追加効果
- PP はない（3vs3 ならほぼ気にならないため）
- 効果は「状態異常にする」「こんらんさせる」「ランクを変える（自分 / 相手）」の3種類。1つの技に複数持てる
  - 攻撃技の効果は追加効果。当たってダメージが出た後に 〇% で起きる。決まらなくても文は出さない
  - 変化技（威力 0）は効果そのもの。すでに状態異常・タイプで効かないときは「しかし うまく きまらなかった！」、ランクが上限なら「もう あがらない！」
  - 自分だけにかける変化技は命中判定をしない（必ず決まる）
- 優先度は +1 の先制技（すべりこみ / ゆきつぶて / しのびより）だけ。技名は原作と被らないオリジナル（§1.2）

### 4.3 ダメージ

ポケモンと同じ式を使う（Lv50）。

```text
ダメージ = ((22 × 威力 × 攻撃 ÷ 防御) ÷ 50 + 2)
          × 急所(1.5) × 乱数(0.85〜1.00) × タイプ一致(1.5) × 相性 × やけど(物理なら0.5)
```

- 計算は式の左から順に掛け、掛けるたびに小数を切り捨てる。相性が 0 でなければ最低 1 ダメージ
- 物理技は こうげき / ぼうぎょ、特殊技は とくこう / とくぼう を使う
- 急所は 1/24。急所のときは自分の下がった攻撃ランクと相手の上がった防御ランクを無視する
- 命中は「技の命中 × 命中ランク ÷ 回避ランク」。原作と同じく（自分の命中ランク − 相手の回避ランク）を -6〜+6 に収めた1つの倍率で掛ける
- 乱数は `System.Random`（オンラインはホストの乱数だけを使う）

### 4.4 状態異常

| 状態 | 効果（原作に準拠） |
| --- | --- |
| まひ | すばやさ半分、1/4で動けない |
| どく | ターン終わりに最大HPの1/8 |
| もうどく | ターン終わりに 1/16, 2/16, 3/16…と増える |
| やけど | ターン終わりに 1/16、物理のダメージ半分 |
| ねむり | 1〜3ターン動けない。その次のターンに目を覚まして、そのまま動ける |
| こおり | 1/5で解ける（解けたターンは動ける）。ひタイプの技を受けると解ける |
| こんらん | 1〜4回、技を出す前に 1/3 で自分を攻撃（威力40の物理・タイプなし）。交代で治る |

- まひ・どく・もうどく・やけど・ねむり・こおりは1体に1つだけ。交代しても残る（もうどくのダメージの段階だけは交代で 1/16 に戻る）
- こんらんは別枠なので、状態異常と重なる
- タイプで効かない: ひ は やけど、こおり は こおり、かみなり は まひ にならない
- 技を出す前の判定は ねむり・こおり → こんらん → まひ の順
- ターン終わりのダメージは すばやさの高い側から（同速は自分側から）。ダメージは最低 1
- 状態異常の印（色付きの札）を名前の枠に出す。こんらんは印なし
- 名前はオリジナルにするかは未定（「まひ」「どく」は一般名詞なのでそのままでもよい）

### 4.5 能力変化（ランク）

- こうげき〜すばやさ・命中・回避が -6〜+6
- 倍率は原作どおり（2/8 〜 8/2、命中・回避は 3/9 〜 9/3）
- 交代すると元に戻る
- 上がった / 下がった量で「ぐーんと」「がくっと」が付く。上がると青、下がると赤にペンモンが光る

### 4.6 特性・持ち物

- 特性・持ち物はペンモンごとに1つずつ固定。どのペンモンが何を持つかは定義表 `MonsterTable` が正（ずかんで確認できる）
- ドラフトのカードに名前と短い説明を出す。バトルでは働いたときに文を出す（ダメージの倍率だけのものは文なし）
- ダメージの倍率は、原作の「その他の補正」と同じく式の最後（やけどの後）に掛けて切り捨てる
- 「1回だけ」の持ち物は使うとそのバトル中は無くなる（交代しても戻らない。試合ごとに戻る）
- 数値は `BattleBalance`（`IntimidateStages` / `LastStandMultiplier` / `FeatherMultiplier` など）

| 特性 | 効果 | いつ |
| --- | --- | --- |
| こわもて | 相手の こうげき を1段下げる | 場に出たとき（バトル開始時は両方出てから、すばやさの高い側から） |
| せとぎわ | HP が 1/3 以下のとき、タイプ一致の技のダメージ 1.5 倍 | ダメージ計算 |
| ふかふかしぼう | こおり・ひ の技で受けるダメージ半分 | ダメージ計算 |
| ビリビリボディ | 物理技を受けたら 30% で相手を まひ | 攻撃を受けたあと |
| どくぬめり | 物理技を受けたら 30% で相手を どく | 攻撃を受けたあと |
| とげとげはだ | 物理技を受けたら、相手に相手の最大HPの 1/8 のダメージ | 攻撃を受けたあと |
| よふかし | ねむり にならない | 状態異常になるとき |
| おいかぜのり | すばやさ が1段上がる（もう上がらないときは何も出さない） | ターン終わり |
| いきおいづく | 相手をたおしたら こうげき が1段上がる | 攻撃したあと |
| かたいはね | 急所に当たらない | ダメージ計算 |

| 持ち物 | 効果 | いつ |
| --- | --- | --- |
| ほしざかな | 最大HPの 1/16 回復 | ターン終わり |
| おやつのイカ | HP が半分以下になったら最大HPの 1/4 回復（1回だけ） | HP が減ったとき |
| さっぱりこんぶ | 状態異常になったらすぐ治す（1回だけ。こんらんは治さない） | 状態異常になったとき |
| ゆうきのはね | 物理技のダメージ 1.2 倍 | ダメージ計算 |
| かしこいはね | 特殊技のダメージ 1.2 倍 | ダメージ計算 |
| いのちのつらら | 攻撃技のダメージ 1.3 倍。当てるたびに自分の最大HPの 1/10 減る | ダメージ計算 / 攻撃したあと |
| めききメガネ | ばつぐんの技のダメージ 1.2 倍 | ダメージ計算 |

- 文の例: 「〇〇の こわもて！」→ 効果の文 / 「〇〇は ほしざかなで HPを かいふくした！」/「〇〇は ふんばりマフラーで もちこたえた！」

### 4.7 オンラインの制限時間

- 1ターン30秒（`OnlineTurnSeconds`）。過ぎたら一番上の技を自動で使う
- ひんしの後の入れ替えも30秒。過ぎたら出せる中で一番上のペンモンを出す
- 残り秒数は画面の上に「のこり N びょう」と出す（ドラフト・選出は右上）。CPU 戦では出さない

### 4.8 CPU

| 賢さ | 行動 |
| --- | --- |
| よわい | 技をランダムに選ぶ。ひんしの後は控えの先頭を出す |
| ふつう | 一番ダメージが出る技を選ぶ（乱数なし・急所なしで計算し、命中率を掛けた見込み。変化技は 0 とみなし、全部 0 ならランダム） |
| つよい | ふつう ＋ 不利なら交代する。ひんしの後は相性のいいペンモンを出す |

- 「不利」= 相手の攻撃技に ばつぐん を取られていて、こちらの攻撃技はどれも ばつぐん を取れないとき。タイプ相性だけで見る
- 交代先は「こちらの通りやすさ − 相手の通りやすさ」（攻撃技の一番いい相性の倍率どうしの差）が今より大きく、自分も不利でないペンモン。いなければ交代しない
- 勝ち抜き戦での切り替え（案）: 1〜3戦目 よわい / 4〜6戦目 ふつう / 7戦目から つよい。ボスはいつも つよい
- チームの強さ（案）: CPU のドラフトで、連勝数 × 10%（最大 100%）の確率で提示のうち種族値の合計が一番高いのを取る（それ以外はランダム）。24 体は合計が 440〜475 にそろっているので差は小さい。体数が増えたら効いてくる
- 数値は `BattleBalance`（`NormalCpuFromWins` / `StrongCpuFromWins` / `BossInterval` / `CpuStrongPickPercentPerWin`）

## 5. 成長・収集

- 育成・収集はない。記録は勝ち抜き戦の最高連勝数だけ

## 6. 画面・ビジュアル

- 横画面固定（Android / Windows / ブラウザ）
- バトル画面はダイヤモンド・パール風: 手前左に自分（後ろ姿）、奥右に相手（正面）。HPバーと名前の枠、下にメッセージ窓とコマンド
- ペンモンの絵はコードで生成するドット絵。1体につき正面と後ろの2枚（64x64）。実行時に No ごとのデザインから作る
- ポケモンのように1体ずつシルエットから描き分ける（共通の胴体＋小物では全員同じ形に見えたため）。タイプのイメージ（§3.3）を形にする。例: シャチペンは横長で背びれ、イワペンは岩を背負う、カザンペンは体が火山、アラシペンは体が雲
- 全員に共通させるのは「ペンギンの顔」だけ: 白い顔、小さめの丸い目（縦2ドットの光）、オレンジのくちばし、ピンクのほっぺ。大きな黒目は怖く見えたので使わない。表情づけに にっこり目（^ ^）も使う
- 後ろ姿は正面と同じ形で、顔とおなかの白を塗らず、左右を反転する（自分側は右の相手のほうを向く）
- 定義表にない No はふつうのペンギン（ペンタ）の絵で代用する
- 背景は空（上ほど濃い青）と地面（緑）。ペンモンは楕円の台座の上に立つ
- 名前の枠: 名前・タイプ・Lv50・HPバー。HPバーは 50% 以下で黄、20% 以下で赤。数字は自分側だけ出す

## 7. UI・演出・サウンド

- メッセージは「こうかは ばつぐんだ！」のような一文ずつの送り表示（速さは設定で変えられる）。文字を1つずつ出し、送り中のタップで全文、読み終わったら▼を出してタップで次へ（窓の外の場をタップしてもよい）
- 「ゆけっ！」「〇〇の △△！」「もどれ！」の文はタップを待たず、そのまま登場・攻撃の演出へつなげる
- コマンドは「たたかう / ペンモン」の2つ（にげるは無い）。たたかう → 技4つ（タイプの色付き）＋もどる
- 演出

| 場面 | 演出 |
| --- | --- |
| 出てくる | 足元から「ぽよん」と大きくなる |
| もどる | 小さくなって消える |
| 技を使う | 相手の方へ踏み込んで戻る |
| ダメージ | 点滅してから HP バーが少しずつ減る |
| ひんし | 台座の下へ沈んで消える |
| 状態異常になる / こんらんする | その色にふわっと2回光る（まひ 黄・どく 紫・やけど 赤・ねむり 灰・こおり 水色・こんらん ピンク）。名前の枠に印が付く |
| 能力が上がる / 下がる | 青 / 赤に光る |
| どく・やけど・自分を攻撃 | 点滅して HP が減ってから、理由の文を出す |

- 効果音は仮でコード生成（決定・技・当たり（相性で3種）・登場・ひんし・勝ち・負け・状態異常・能力アップ / ダウン）。BGM は未定

## 8. オンライン

- 参加コードを共有して離れた2人が1対1で対戦する（ランダムマッチはしない）
- タイトルの「オンライン対戦」→ 部屋を作る / コードで参加 → ドラフト → 見せ合い・選出 → バトル → 結果 → タイトル（1試合ごとに部屋を作り直す。再戦ボタンはない）
- 接続は共通基盤（`OnlineSession` / `ModeSelectPanel`）を使う。ModeSelectPanel の「CPUと対戦」は隠す（CPU 戦はタイトルの勝ち抜き戦から入る）
- ホストだけがバトルとドラフトの抽選を計算し、ゲストは選んだ行動を送って結果を表示する
  - ドラフトはホストが決めた種でゲストの端末が引く（§2.1）
  - バトルはホストが陣営 0、ゲストが陣営 1。ゲストはホストから届いた `BattleEvent` で写しの状態（HP・状態異常・場・勝敗）を更新して再生する
  - ゲストの画面では自分が手前になるよう、写しの陣営を入れ替えて持つ
- 相手が切断したら（ドラフト中・選出中も含む）「あいてが せつだんしました」を表示して勝ち扱い。決着の後の切断は無視する
- オンライン対戦の勝敗は記録しない

### 8.1 メッセージ一覧

1つの名前付きメッセージ（`penmon.link`）に「種類・int の個数・int の列」を載せて送る。確実に順番どおり届く送り方（ReliableFragmentedSequenced）を使う。届いたものは種類ごとに貯め、待つ側が取り出す。

| 種類 | 向き | 中身 | いつ |
| --- | --- | --- | --- |
| DraftSeed | ホスト → ゲスト | ゲストのドラフトの種（1個） | 接続した直後 |
| Six | お互い | ドラフトで取った6体の No | ドラフトが終わったら |
| Team | お互い | 選出した3体の No（並びが出す順） | 選出を決めたら |
| Action | ゲスト → ホスト | 行動（0 = 技 / 1 = 交代, 技の番号 or 選出の何番目か） | 毎ターン |
| Replace | ゲスト → ホスト | ひんしの後に出す選出の何番目か | ゲストのペンモンがひんしになったら |
| Events | ホスト → ゲスト | `BattleEvent` の列（1個 8 int: 種類・陣営・選出の何番目か・技の番号・HP・状態異常・能力・量） | バトル開始・毎ターン・ひんしの入れ替え |

- ひんしの入れ替えは、両方ひんしならホストが両方そろうのを待ち、まとめて1回の Events で送る
- 陣営はホストから見た番号で送り、ゲストが受け取るときに入れ替える

## 9. セーブ

- 勝ち抜き戦の最高連勝数、設定（音量・メッセージの速さ）
- 音量は共通基盤の `AudioManager` が保存する（設定画面を閉じたとき）。メッセージの速さは `GameSettings`（PlayerPrefs）に、押したときに保存する
- 最高連勝数は共通基盤の `BestScore`（PlayerPrefs）に保存する。勝つたびに更新するので、途中でやめても記録は残る
- 勝ち抜き戦の途中経過は保存しない（案）。1回が短めなのと、6体と連勝数を復元する手間に見合わないため。アプリを閉じたらその回はおしまい
